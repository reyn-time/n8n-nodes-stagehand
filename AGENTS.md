## Ticket delivery

- Before approving ticket work, check every acceptance criterion against the implementation and its evidence. Record an explicit pass or gap for each criterion; inspect relevant runtime and dependency contracts where behavior depends on them.
- Once review confirms every criterion passes, commit the work, push it to `master`, then close the ticket with a brief implementation summary. Keep the ticket open if any criterion remains unmet.
